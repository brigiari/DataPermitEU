# Screenshots

Screenshots are not committed to this repository. To capture your own, run the app locally and
visit the routes below.

```bash
npm install
npm run dev
```

| Suggested filename | Route | What to capture |
| --- | --- | --- |
| `01-landing.png` | `/` | Hero, independence disclaimer panel, six-step workflow |
| `02-projects.png` | `/projects` | Both demo projects with readiness meters and finding counts |
| `03-catalogue.png` | `/catalogue` | Facet sidebar with live counts, result grid, relevance banners |
| `04-dataset-profile.png` | `/catalogue/scor-se` | Variable table, provenance panel, quality meters, access conditions |
| `05-compare.png` | `/projects/demo-adherence-readmission/compare` | Governing constraints, pairwise compatibility cards |
| `06-builder.png` | `/projects/demo-adherence-readmission/application` | Five-step nav, autosaving fields, inline guidance sidebar |
| `07-variables.png` | `/projects/demo-adherence-readmission/application` | Scope step, variable selector with per-variable justifications |
| `08-minimisation.png` | `/projects/demo-adherence-readmission/minimisation` | Sensitivity distribution bar, MIN findings with evidence expanded |
| `09-readiness.png` | `/projects/demo-adherence-readmission/readiness` | Overall score, six section meters, blocking findings, export panel |
| `10-tracker.png` | `/tracker` | Pipeline columns and per-application access-body detail |
| `11-methodology.png` | `/methodology` | Published rule catalogue with signals and known weaknesses |
| `12-print.png` | `/projects/demo-adherence-readmission/readiness/print` | Print-ready application with the fictional-output banner |

## Tips

- Capture at 1440 px wide for the desktop layouts, and 390 px for a mobile pair.
- On the minimisation page, expand "Show the evidence behind this" on at least one finding — the
  disclosure is the point of the design.
- The methodology page is worth capturing scrolled to a rule's "Known weakness" block.
- Reference the images from the README's screenshots section once captured.
